# Third-party components

The repository ships no third-party code, models or datasets. The demo datasets in `fluent_data_studio/datasets/`
are generated by `fluent_data_studio/demo.py` from a fixed random seed; every company, product, customer key,
campaign, carrier and number in them is invented. Port and city names are used as plain place names.

## Required by the desktop application (not in this repository)

The engine and the command line in this repository need only DuckDB and openpyxl.

## Required, installed from PyPI

| Component | Licence | Use |
|---|---|---|
| FluentQt Community | GPL-3.0 or the FluentQt commercial licence | Application shell, navigation, dialogs, forms, settings, theming. |
| FluentQt Pro | Proprietary (see FluentQt Pro's `LICENSE`) | Data grid, charts (ChartView, PieChart, HeatmapChart), dashboard layout, chat input, node graph. |
| [PyQt5](https://www.riverbankcomputing.com/software/pyqt/) / Qt 5 | GPL-3.0 (PyQt5); LGPL-3.0 (Qt) | Qt bindings (the desktop interface only; the engine does not import Qt). |
| [DuckDB](https://duckdb.org/) | MIT | The local analytical database: staging, profiling, every transformation and chart query. |
| [openpyxl](https://openpyxl.readthedocs.io/) | MIT | Reading Excel workbooks. |

## Optional

| Component | Licence | Use |
|---|---|---|
| [psycopg 3](https://www.psycopg.org/) (`psycopg[binary]`) | LGPL-3.0 | PostgreSQL connector (`pip install "fluent-data-studio[postgres]"`). |
| A language model behind an OpenAI-compatible endpoint | Chosen and installed by the user | Planning requests and writing findings; no model is bundled or downloaded by the application. |

The OpenAI-compatible client is written against the public HTTP interface with the Python standard library; no SDK
is used. Because the application links GPL components, it is distributed under GPL-3.0-or-later. A distributed build
that contains FluentQt Pro requires Pro to be available under GPL-compatible terms for that build.
